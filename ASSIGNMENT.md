## Суть
Responsive CRUD-приложение с токен-аутентификацией на **Angular 20** (front) и **.NET 9 C# API** (back).
Bootstrap + Font Awesome, страница **"Mina citat"**. Срок — 2 недели.

## Требования

### Books CRUD
- Страница со списком всех книг.
- Стартовая страница с кнопкой «Lägg till ny bok» → форма (напр. titel, författare, publiceringsdatum).
- После submit — редирект обратно на список, новая книга видна.
- У каждой книги кнопка «Redigera» → форма редактирования → редирект на список с обновлёнными данными.
- У каждой книги кнопка «Radera» → книга удаляется из списка.

### Токены (JWT)
- Аутентификация через JWT.
- Страница логина (username + password).
- Регистрация нового пользователя, затем логин им.
- После успешного логина back-end генерит токен, отдаёт на front.
- Front хранит токен (localStorage или cookie) и шлёт его во все API-запросы.
- Валидация токена на back-end: CRUD доступен только аутентифицированным.

### Mina citat
- Отдельная вью «Mina citat».
- Меню для переключения между вью книг и вью цитат.
- Пользователь может добавлять / удалять / редактировать **свои** цитаты.

### Responsive
- Layout адаптируется под desktop / tablet / mobile.
- Навигация коллапсит в мобильное меню на малых экранах.
- Корректные отступы/выравнивание элементов на всех вьюпортах.

### Bootstrap + Font Awesome
- Bootstrap для верстки и стилизации кнопок/форм/компонентов.
- Font Awesome иконки, отображаются корректно по всему приложению.

### Доп. челлендж
- Кнопка переключения светлой/тёмной темы (UX).

### Сдача
- Задеплоить на бесплатный хостинг (Netlify / Vercel / Azure Static Web Apps).
- Прислать ссылку на живой сайт + GitHub репозиторий.

## ⚠️ Причина отклонения v1 (письмо от 27.08.2026) — КЛЮЧЕВОЕ
Marco отклонил первую версию. Требование, которое было не выполнено:

- В приложении должны быть **5 собственных избранных цитат**, которые **уже готовы** (предзаполнены).
- Эти 5 цитат обычный пользователь должен **только видеть/читать** — НЕ редактировать и НЕ удалять.
- Редактировать/удалять их может **только твой (author) аккаунт**.
- Аналогично «Mina citat»: чужие цитаты пользователь трогать не может — **только владелец** удаляет свои.

## Итоговая модель цитат (по письму Marco, финал 31.08.2026)
> ⚠️ История: сначала seed → потом ошибочно переделали на user-generated → Marco снова уточнил: 5 цитат должны быть **уже вшиты** (färdiga), read-only, а юзеры дополнительно ведут свои. Вернулись к seed + свои.

Финальное поведение (реализовано и проверено на проде):
- **5 featured-цитат вшиты в приложение** (`IsSeed=true`, `UserId=null`), реконсилятся на старте в `api/Program.cs`. Видны всем, **только чтение** — редактировать/удалять нельзя (PUT/DELETE seed → 404). Секция «Utvalda citat 🔒 Skrivskyddad».
- **Плюс каждый юзер добавляет свои цитаты** (форма «Add a quote you like»); править/удалять их может **только владелец** (`!IsSeed && UserId == me`).
- `GET /api/quotes` → 5 seed + собственные цитаты текущего юзера (не чужие). DTO: `{id,text,author,isSeed,mine}`.
- Схема: колонка `IsSeed` в модели; на старте `ALTER TABLE Quotes ADD COLUMN IsSeed ... DEFAULT 0` в try/catch (безопасно при персистентной БД без миграций).
